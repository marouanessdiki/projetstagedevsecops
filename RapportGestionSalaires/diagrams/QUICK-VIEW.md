## 🎯 **Step-by-Step Visualization**

### **Method 1: Direct VS Code Viewing**
1. Open VS Code
2. Navigate to `RapportGestionSalaires/diagrams/`
3. Click any `.eraserdiagram` file
4. **Eraser extension will auto-render the diagram**

### **Method 2: Preview Mode**
1. Right-click on `.eraserdiagram` file
2. Select **"Open Preview"**
3. View rendered diagram in side panel

### **Method 3: Split View**
1. Open `.eraserdiagram` file
2. Press **`Ctrl+K V`** (or `Cmd+K V` on Mac)
3. See code and preview side by side

## 🔧 **Troubleshooting**

### **If diagrams don't render:**
1. **Check Eraser extension is installed and enabled**
2. **Restart VS Code**
3. **Try opening the file again**

### **If you see only code:**
1. **Look for a preview button** in the top-right corner
2. **Try right-clicking** and selecting "Open Preview"
3. **Check if Eraser extension is active** in the Extensions panel

## 📱 **Alternative: Online Mermaid Viewer**

If VS Code extension doesn't work:
1. **Copy the Mermaid code** from any `.eraserdiagram` file
2. **Go to**: https://mermaid.live/
3. **Paste the code** and view online
