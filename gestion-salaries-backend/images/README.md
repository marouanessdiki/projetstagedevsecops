# Images Directory

## Required Images

### `logo.png`
- **Purpose**: Company logo for PDF headers
- **Size**: 200x200px+ (scaled to 50x50 in PDF)
- **Format**: PNG with transparent background

### `cachet.png`
- **Purpose**: Company stamp for PDF signatures
- **Size**: 300x300px+ (scaled to 80x80 in PDF)
- **Format**: PNG with transparent background

## Usage

Images are automatically included in generated PDF attestations. If not found, text alternatives are used.
